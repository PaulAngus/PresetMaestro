# Preset Maestro 1.2.29

## Device state and scene names

- FM9 polling checks observed saved changes without copying unsaved live names into the browsing library. Saved scene swaps use the existing conservative tag-following rules and confirmation where needed.
- The first device sync now saves scene names under the MIDI port pair selected for that connection.
- Cancelling a background preset dump no longer forces a 15-second pause when its complete, validated reply arrives promptly. Incomplete or corrupt replies retain the late-response quarantine.
- Use Current in the Favorites editor rejects late replies after another draft, edit, profile or connection has replaced the original request.

## Entry and presentation

- Preset Sender accepts four digits for 1,024-slot devices, including auto-send. The option is labelled **Auto-send full numbers**; favorites continue to use three digits.
- Scene tag summary pills use the same theme-aware styling as preset tags.
- Added a task-based user manual, screenshots and PDF guides.

## Packaging

- Windows publishing creates an explicitly populated EXE/notices ZIP and SHA-256 sidecar after signing checks.
- Mac archive publishing creates a SHA-256 sidecar; app-only publishing removes stale archive/checksum pairs.
- Local Mac validation retains testing archives and their checksums. Public signing and notarization requirements remain in the [release guide](../github-releases.md).

## Validation

The software Release suite passes 954 cases with no failures; the ten physical cases are enabled separately. All ten passed on FM9 firmware 12.00 through the saved MIDI Forwarder route, using MIDI channel 1 and Scene CC 34. The application matrix recorded 100 matching readbacks, including restoration checks. A full scan checked 512 slots with zero errors, and compatibility verified 336 amp names and all eight scenes in six presets. See [hardware scope and evidence](../hardware-tests.md#forwarded-fm9-acceptance-and-correction-20-october-2026).

Windows/macOS build and workflow evidence is documented in the [platform guide](../windows-macos-development.md). These results do not establish physical FM3/Axe-Fx III support or every audio, driver, controller and clean-host scenario.
